# NeuralVerge API

AI research, web extraction, search, and data enrichment platform exposing a REST API, a public OpenAPI contract, an llms.txt docs index, and a hosted remote MCP server. Capabilities include multi-step AI Research, schema-driven AI Extract, reusable AI Agents workflows, synchronous Search, and 29 data sources spanning company intelligence, corporate registries, contact enrichment, email/phone lookup, and LinkedIn data.

## APIs

- **NeuralVerge REST API** — REST API for AI Research, AI Extract, AI Agents, Search, and Data Sources. Bearer token auth (Authorization: Bearer <API_KEY>). Endpoint paths follow the /functions/v1/{action} pattern (e.g. POST /functions/v1/run-research, /functions/v1/run-search). (`https://api.neuralverge.ai`)

> Confirmed publicly reachable: REST API base https://api.neuralverge.ai (Bearer auth), OpenAPI 3.0.0 at https://docs.neuralverge.ai/openapi.json, and llms.txt at https://docs.neuralverge.ai/llms.txt (docs subdomain; root neuralverge.ai/llms.txt not found). A hosted remote MCP server exists and is compatible with Claude/ChatGPT/Cursor via Authorization: Bearer header, but the exact MCP endpoint URL is NOT publicly published (deferred to docs behind login), so no MCPServer property is cataloged. No public GraphQL, AsyncAPI, or Postman collection found, and no distributable agent skills (AI Agents are server-side saved workflows, not client-side skills). Marketing pages show illustrative paths like /v1/research and /v1/extract, but authoritative paths are /functions/v1/. Minor discrepancy: site says 29 data sources vs submitted apis.json's 30.
